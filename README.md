# 🛍️ ShopBot — Магазин товаров с Telegram ботом

Простой и удобный каталог товаров с покупкой через Telegram бот. Фиолетово-белый дизайн, админ-панель, SEO-оптимизация, защита от DDoS.

## ✨ Возможности

- 🎨 **Фиолетово-белый дизайн** — современный и привлекательный
- 🤖 **Интеграция с Telegram** — кнопка "Купить" открывает бота
- 🔐 **Админ-панель** — управление товарами и категориями
- 🔍 **SEO-оптимизация** — мета-теги для каждого товара и категории
- 🛡️ **Защита от накрутки** — rate limiting (10 кликов/минуту)
- 📱 **Адаптивный дизайн** — работает на всех устройствах
- 💾 **Локальное хранение** — данные сохраняются в браузере

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск в режиме разработки

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

### 3. Сборка для продакшена

```bash
npm run build
```

Готовые файлы появятся в папке `dist/`.

## 🔧 Настройка

### 1. Измените ссылку на Telegram бота

В админ-панели → вкладка "⚙️ Настройки" → замените ссылку:

```
Быстро: https://t.me/your_bot?start=buy
Замените на: https://t.me/ВАШ_БОТ?start=buy
```

### 2. Измените пароль админ-панели

В файле `src/App.tsx` найдите строку:

```typescript
const savedPassword = localStorage.getItem('shop_admin_password') || 'admin123'
```

Замените `admin123` на свой пароль:

```typescript
const savedPassword = localStorage.getItem('shop_admin_password') || 'мой_секретный_пароль_123'
```

### 3. Обновите домен в index.html

Замените `your-domain.com` на ваш реальный домен:

```html
<!-- Было -->
<link rel="canonical" href="https://your-domain.com/" />

<!-- Стало -->
<link rel="canonical" href="https://myshop.ru/" />
```

## 📦 Развёртывание на хостинге

### GitHub Pages (рекомендуется)

1. Создайте репозиторий на GitHub
2. **Важно:** В файле `vite.config.js` укажите имя репозитория:
   ```javascript
   export default defineConfig({
     base: '/имя-репозитория/',  // Например: '/lerochka/'
     // ... остальные настройки
   })
   ```
3. Пересоберите проект: `npm run build`
4. Загрузите файлы из папки `dist/` в репозиторий
5. Settings → Pages → Source: **GitHub Actions**
6. Сайт будет доступен по адресу: `https://ваш-username.github.io/имя-репозитория/`

**Пример:** Если репозиторий называется `lerochka`, то:
- В `vite.config.js`: `base: '/lerochka/'`
- URL сайта: `https://username.github.io/lerochka/`

### Netlify (drag & drop)

1. Зарегистрируйтесь на [netlify.com](https://netlify.com)
2. Перетащите папку `dist/` в браузер
3. Сайт готов! Можно привязать свой домен.

### Обычный хостинг (FTP)

1. Купите хостинг (Beget, Timeweb, REG.RU)
2. Скачайте FileZilla
3. Подключитесь к серверу по FTP
4. Загрузите содержимое папки `dist/` в `public_html/`

## 🔍 SEO-оптимизация

### Глобальные настройки сайта

В админ-панели → вкладка "🔍 SEO сайта":
- **Title** — заголовок вкладки (50-60 символов)
- **Description** — описание для поисковика (150-160 символов)
- **Keywords** — ключевые слова через запятую

### SEO для каждой категории

В админ-панели → вкладка "🏷 Категории" → нажмите ✏️ у категории:
- Заполните SEO Title, Description, Keywords
- При выборе категории в каталоге — мета-теги автоматически меняются

### SEO для каждого товара

При добавлении/редактировании товара:
- **SEO Title** — заголовок для поисковика
- **SEO Description** — описание для поисковика
- **SEO Keywords** — ключевые слова через запятую

**Пример:**
```
Товар: Telegram аккаунт
SEO Title: Купить Telegram аккаунт | ТГ аккаунт с гарантией — ShopBot
SEO Description: Купить Telegram аккаунт быстро и безопасно. Готовые ТГ аккаунты с номером.
SEO Keywords: купить тг аккаунт, телеграм аккаунт купить, тг аккаунт с номером
```

## 🛡️ Безопасность

- **Rate limiting**: максимум 10 нажатий "Купить" в минуту
- **Пароль на админ-панель**: защита доступа к управлению
- **Локальное хранение**: данные в localStorage браузера
- **DDoS защита**: рекомендуется подключить Cloudflare
