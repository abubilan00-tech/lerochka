# Руководство по участию в проекте

Спасибо за интерес к проекту ShopBot! Мы рады любому вкладу.

## 🚀 Быстрый старт

1. Форкните репозиторий
2. Клонируйте свой форк:
   ```bash
   git clone https://github.com/ВАШ_USERNAME/shopbot.git
   cd shopbot
   ```
3. Установите зависимости:
   ```bash
   npm install
   ```
4. Запустите проект:
   ```bash
   npm run dev
   ```
5. Создайте ветку для ваших изменений:
   ```bash
   git checkout -b feature/название-фичи
   ```

## 📝 Стиль кода

- Используйте **TypeScript** для всех новых файлов
- Следуйте существующему стилю кода в проекте
- Компоненты React должны быть функциональными с хуками
- Используйте **Tailwind CSS** для стилизации
- Добавляйте комментарии к сложным частям кода
- Имена переменных и функций на английском

## 🔧 Структура проекта

```
src/
├── App.tsx          # Главный компонент приложения
├── main.tsx         # Точка входа
└── index.css        # Глобальные стили
```

## 📤 Отправка изменений

1. Закоммитьте изменения:
   ```bash
   git add .
   git commit -m "feat: описание изменений"
   ```
   
   Формат коммитов:
   - `feat:` — новая функция
   - `fix:` — исправление ошибки
   - `docs:` — изменения в документации
   - `style:` — форматирование кода
   - `refactor:` — рефакторинг
   - `test:` — добавление тестов
   - `chore:` — рутинные задачи

2. Отправьте в свой форк:
   ```bash
   git push origin feature/название-фичи
   ```

3. Создайте Pull Request в основной репозиторий

## ✅ Перед отправкой PR

- [ ] Код компилируется без ошибок (`npm run build`)
- [ ] Все функции работают корректно
- [ ] Обновлена документация (если нужно)
- [ ] Добавлен запись в CHANGELOG.md (если нужно)
- [ ] Код соответствует стилю проекта

## 🐛 Нашли ошибку?

Создайте Issue с описанием:
- Что вы делали
- Что ожидали
- Что произошло на самом деле
- Шаги для воспроизведения
- Скриншоты (если возможно)

## 💡 Есть идея?

Обсудите её в Issues перед реализацией, чтобы убедиться, что она соответствует видению проекта.

Не стесняйтесь задавать вопросы в Issues или Discussions.
