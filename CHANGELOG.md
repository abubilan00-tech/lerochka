# Changelog

Все значимые изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] - 2024-01-XX

### Добавлено
- Initial release
- Каталог товаров с фильтрацией по категориям
- Админ-панель для управления товарами и категориями
- SEO-оптимизация для каждого товара и категории
- Глобальные SEO-настройки сайта
- Интеграция с Telegram ботом
- Защита от накрутки кликов (rate limiting)
- Адаптивный дизайн (мобильная версия)
- Фиолетово-белая цветовая схема
- Полная инструкция по настройке (19 шагов)
- Автоматический деплой через GitHub Actions
- Локальное хранение данных (localStorage)

### Технологии
- React 18.2
- TypeScript 5.7
- Vite 6.3
- Tailwind CSS 4.1
- Font Awesome 6.4
